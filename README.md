# Content Factory — landing page

Одностраничный продающий сайт для услуги автоматизации контента.

## Быстрый запуск локально
Откройте `index.html` в браузере.

## Публикация через GitHub Pages
1. Создайте новый репозиторий на GitHub.
2. Загрузите **содержимое этой папки** в корень репозитория.
3. Откройте `Settings → Pages`.
4. В `Build and deployment → Source` выберите **GitHub Actions**.
5. Workflow `Deploy static site to Pages` автоматически опубликует сайт.

После первого успешного запуска ссылка будет видна в `Settings → Pages` и в выполненном Action.
